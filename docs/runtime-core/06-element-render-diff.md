## 能聊聊 Vue 3 是如何处理一个普通 Element 从渲染到更新的全过程吗？

好的，面试官，我觉得这部分整体上可以分成三大步

第一部分是分流。render 函数其实是一个由虚入实的过程，其中 patch 就是整个渲染工作的主要入口
再 patch 中，他不会关心具体的操作逻辑，而是根据 vnode 的 type 和 shapeFlag 进行位运算决断出到底是要做什么样的处理，文本、元素还是组件

第二部分是执行。再 processElement 中，有两个方向，分别是挂载和更新。
在 mount 中，会完成初始结构的搭建，比如创建节点，子节点，初始设置属性等等，给后续的优化更新埋点
在 patch 中，主要是根据编译时标记的 patchFlag 的靶向标记，以及 block tree，来做快速处理或者是全量比较

第三部分是核心，是重点，最后的攻坚战。也是 diff 算法的核心。
首先就像一个双向拉链一样，从两头往中间比较，这个过程得到的结果是要么直接结束，要么就剩余一些乱序的节点。
然后对于这些乱序的节点，通过 newIndexToOldIndexMap 建立一个映射关系，然后通过创建最小递增子序列，找出新节点中的钉子户
让那些非钉子户节点按照新的顺序移动，如果旧节点在新节点中找不到就删除，新节点在旧节点中找不到就新增
