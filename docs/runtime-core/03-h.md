## h 函数的使命

总体来说，h 函数首先对参数进行增强，将参数区分为 type、props、children，然后调用 createVNode 方法，最终根据 type 的类型，以及 children 的类型，得到一个能完整描述的 vnode。

因此它不光是为了创建一个 vnode，还在做 “情报收集” 工作。

1. 首先需要自己是谁：通过 type 初步得到 shapeFlag（元素，组件，Teleport 等等）
2. 知道子节点是什么：通过 normalizeChildren 判断出来子节点 type 是什么，然后更新 vnode 的 shapeFlag
3. 更新怎么做：通过 patchFlag 和 Block 系统，告诉未来的渲染器，哪些是动的部分，哪些是静的部分

这部分暂时可以保持着 “上帝视角” 的感觉去理解，因为这部分都是在埋伏笔，真正的大戏在更新阶段。

还要说明一点，这里的 patchFlag 只是被动接收，关于这个属性的计算规则和逻辑，主要在编译器部分。
