## 双向收集的本质

正向收集 Dep -> Effect 是为了响应

反向收集 Effect -> Dep 是为了卸载。

这让 Vue 的响应式系统具备了完整的生命周期，而不是一个只管发通知、不管收尾的 “烂摊子”

## 关于依赖扩散

Vue3 的 trigger 不是简单的点对点通知，而是基于操作语义的关联点名。他深知数组下标和 length、对象属性跟迭代器（ITERATOR_KEY）之间的逻辑耦合，从而保证了响应式的完备性。

## 关于自我保护

effect !== activeEffect 的判断是响应式引擎的 “断路器”。它默认屏蔽数据流中的 “回环”，确保了系统的稳定性。而 allowRecourse 则体现了框架的灵活性————将递归深度控制的权力和责任交给理解业务逻辑的开发者。
